Getting Started with ConverseR

ConverseR integrates OpenRouter language models directly into RStudio. Chat with an assistant that automatically understands your active script and .GlobalEnv objects, make quick inline code edits via keyboard shortcut, share plots, and guide coding behavior with custom skill files.

1 Overview & Installation (macOS & Windows)

ConverseR provides two tools that share your active script context, .GlobalEnv data summaries, and model settings:

converser() — Interactive Sidebar

Opens in the RStudio Viewer pane while keeping your R Console free for coding. Use it to ask questions, diagnose errors, share plots, preview code diffs, and manage settings.

converser_inline() — Inline Code Assistant

A compact prompt bar designed to be bound to a keyboard shortcut. Highlight code in your script, enter a quick instruction, and replace or insert code directly.

Installing ConverseR (macOS & Windows)

Run the following in your RStudio Console to install ConverseR and all required CRAN dependencies automatically:

R Console — Install with All Dependencies 
if (!requireNamespace("remotes", quietly = TRUE)) install.packages("remotes")

# Option A: Install from GitHub
remotes::install_github("tironesr/ConverseR", dependencies = TRUE)

# Option B: Or install from a shared ConverseR_0.4.0.tar.gz bundle file
# remotes::install_local(file.choose(), dependencies = TRUE)

2 Understanding OpenRouter & Getting an API Key

What is OpenRouter?

OpenRouter is a unified API gateway that gives you access to hundreds of leading language models—including Anthropic Claude, OpenAI GPT, Google Gemini, DeepSeek, Qwen, and Mistral—through a single account and a single API key. Instead of managing separate accounts and monthly subscriptions across multiple AI vendors, OpenRouter lets you switch between models at any time from one interface.

What Signing Up Requires

  1. Create an Account: Visit https://openrouter.ai and sign in using a Google account, GitHub account, or email address.
  2. Add Prepaid Credits: Navigate to Settings → Credits (openrouter.ai/settings/credits). OpenRouter operates on a pay-as-you-go basis with no recurring monthly subscription. Adding a small balance (such as $5–$10) is typically sufficient for thousands of R coding and data science requests.
  3. Generate an API Key: Navigate to Settings → Keys (openrouter.ai/settings/keys), click Create Key, give it a name (e.g., ConverseR), optionally set a credit limit, and copy the resulting key (which begins with sk-or-v1-...).

What Your OpenRouter API Key Allows You to Do in ConverseR

  • Switch Models Anytime: Choose from the Top 20 OpenRouter models in the Sidebar dropdown—or search the full catalog of 400+ models—to match the task at hand (e.g., fast everyday coding vs. complex statistical modeling).
  • Enforce Privacy & Zero Data Retention (ZDR): Restrict requests exclusively to providers that do not retain data or train on your code and environment summaries.
  • Control Thinking / Reasoning Depth: Adjust reasoning effort (None, Minimal, Low, Medium, High) across supported reasoning models from a single menu.
  • Use Vision Capabilities: Attach active RStudio plots via Share Plot when using multimodal models.

3 Saving Default Settings (No .Rprofile Editing Required)

ConverseR includes built-in persistent configuration storage. You do not need to manually edit .Rprofile or .Renviron to keep your API key, model, or skills across R sessions.

Method A: Save Defaults via the Sidebar Settings Panel (Recommended)

  1. Run library(ConverseR) and converser() to open the Sidebar in your RStudio Viewer pane.
  2. Click Settings in the top-right header of the Sidebar.
  3. Paste your sk-or-v1-... key into the OpenRouter API Key field.
  4. Select your preferred model, reasoning effort, privacy settings, and optional SKILL.md or .zip skill bundle.
  5. Keep Save as default across R sessions checked at the bottom of the Settings window and click Save & Apply.

Method B: Save Defaults from the R Console

You can also configure and save your defaults from the R Console by setting persist = TRUE:

R Console 
library(ConverseR)

converser_use_openrouter(
  api_key          = "sk-or-v1-your-openrouter-key",
  model            = "deepseek/deepseek-v4.1-flash",
  reasoning_effort = "low",
  zdr              = TRUE,
  data_collection  = "deny",
  persist          = TRUE
)

Once saved, ConverseR automatically loads your API key, model, and skill configuration whenever you run library(ConverseR) in a new R session.

4 Binding a Keyboard Shortcut for Inline Edits

Binding converser_inline() to a keyboard shortcut allows you to highlight code in your script and trigger quick edits without touching the mouse.

  • 1
    In RStudio, open Tools → Modify Keyboard Shortcuts...
  • 2
    Type ConverseR into the Filter... search box.
  • 3
    Click in the Shortcut column next to ConverseR: Inline Code Assistant and press your preferred key combination (for example, Ctrl+Alt+I on Windows/Linux or Cmd+Option+I on macOS).
  • 4
    (Optional) Bind ConverseR: Open Sidebar to Ctrl+Alt+C.
  • 5
    Click Apply.

5 Using the Sidebar (converser())

Run converser() to open the Sidebar. Every code block generated by the assistant includes five actions in its top toolbar:

R CODE
Run in Console Preview Difference Replace Insert in Script Copy
  • Run in Console: Executes the code block directly in your R Console without modifying your active script.
  • Preview Difference: Opens an inline red/green diff comparing your highlighted script selection against the proposed code.
  • Replace: Replaces the currently highlighted text in your script (automatically disabled when no text is highlighted).
  • Insert in Script: Inserts the code at your cursor position in the active script.
  • Copy: Copies the code block to your clipboard.

To revert the most recent script edit made by ConverseR, click Undo in the Sidebar header or run converser_undo().

💡 Sidebar Workflow: Chatting with ConverseR in the Viewer pane, running code in the console, and modifying your script while keeping your console free.

How ConverseR Reads Your Code & Workspace

To keep answers fast, accurate, and budget-friendly, ConverseR is smart about how much code and data it sends to the AI model at one time:

  • Focused by Default (Fast & Inexpensive): When you ask a question or edit code, ConverseR looks only at the specific code chunk you are working in (in Quarto or R Markdown documents), along with any packages loaded at the top of your document. In regular .R scripts, it looks at the code right around your cursor (roughly 125 lines above and below). This keeps responses instant and prevents sending thousands of unrelated lines you aren't currently editing.
  • The "Full Script" Button (When You Need the Big Picture): If you want the assistant to review your entire file from top to bottom, click the Full Script button in the toolbar above the message box. It will turn bright blue and show "Full Script Attached" for your next message.
  • Automatic Recognition for File-Wide Questions: Even if you don't click Full Script, ConverseR automatically senses when you are asking about your whole analysis. If you include phrases like:
    "in this document" • "entire script" • "whole file" • "all figures" • "all chunks" • "all models" • "across the document" • "across the manuscript" • "audit" • "check all" • "consistent"
    ConverseR will automatically include your complete document so it can review everything across your project.
  • Smart Follow-Ups: When having a back-and-forth conversation about an open document, ConverseR only sends the lines you've changed since your last question, saving time and API credits.
  • Workspace Awareness: ConverseR keeps track of all datasets, models, and variables in your R workspace. To keep things clean, it only generates full previews (like column names, sample rows, and regression results) for objects you specifically mention in your question, or the ones you are actively analyzing.

6 Using the Inline Code Assistant (converser_inline())

  1. Highlight code in your R script or Quarto/RMarkdown document (or place your cursor where you want code inserted).
  2. Press your keyboard shortcut (or run converser_inline()).
  3. Select Replace, Insert Before, or Insert After.
  4. Check Preview Difference first to inspect a red/green diff in the Sidebar before modifying your file, or leave it unchecked to stream the code directly into your script.
  5. Type your instruction and press Enter (or click Generate).
Quick & Focused: converser_inline() only reads your active code chunk (or the lines immediately around your cursor). This guarantees instant code edits while using minimal API credits.
💡 Preview Difference: Review red/green diffs in the Viewer before applying.
💡 Direct Replace: Instant in-place streaming into your active editor selection.

7 Sharing Plots & Fixing Errors

  • Share Plot: Click the Share Plot button above the Sidebar input box to attach your active RStudio plot to your next message, then ask any question or request specific visual adjustments.
  • Fix Error: Click Fix Error to diagnose and resolve errors instantly. ConverseR automatically identifies the exact line or block of code that triggered the error (including line numbers from your active script or commands run in the console), inspects your .GlobalEnv objects and error backtrace, and provides ready-to-run corrected code. When the fix is returned, click Run in Console to execute it immediately, or Replace / Preview Difference to update your script.
💡 Share Plot: One-click attaching of active graphics for visual feedback.

8 Model Consultation: Interactive Statistical Guidance

Specifying an empirical model involves nuanced tradeoffs: balancing realism and confounding controls against overfitting, multicollinearity, degrees of freedom, and convergence failures. When you highlight a statistical model in your R script, ConverseR provides dedicated Model Consultation.

How It Works

  • Automatic Context Detection: Whenever you highlight code containing a supported statistical model (e.g., lmer(), lm(), glm(), feols(), brm()), the purple ⚖️ Model Consultation button dynamically appears above the sidebar prompt box. If nothing or non-modeling code is selected, the button remains hidden.
  • Whole-Script & Environment Grounding: Clicking Model Consultation automatically sends your full script pipeline and active .GlobalEnv dataset summaries to the assistant. The model evaluates not just the isolated formula line, but your preceding data cleaning steps, variable transformations, clustering structures, sample sizes, and empirical questions.
Strictly Non-Jargony Statistical Guidance:
Too many statistical tools bury practical insights under dense academic gatekeeping, abstract notation, or exclusionary jargon. ConverseR’s Model Consultation is engineered to communicate in clear, intuitive, and practical English. When technical concepts arise—such as random slopes, shrinkage, singular fits, overdispersion, zero-inflation, link functions, or heteroscedasticity—the consultant immediately translates them into concrete real-world meaning for your specific variables and data structure.

Structured 3-Step Consultation Workflow

1. Diagnose & Understand the Goal

The consultant identifies your response variable, predictors, clustering dimensions, and sample size. If your research objective is ambiguous, it clarifies whether you aim to test a specific causal hypothesis, maximize out-of-sample prediction, or estimate within-subject vs. between-subject effects.

2. Concrete Tradeoffs & Alternatives

Rather than asserting a single "correct" answer, the consultant contrasts 2 to 3 viable specification alternatives (e.g., a simple baseline vs. a maximal random-effects structure, or Poisson vs. Negative Binomial). It explicitly breaks down the practical pros and cons of each in terms of interpretability, power, and risk of misspecification.

3. Ready-to-Run Code & Diagnostics

You receive ready-to-run R code in a standard code block with concise inline comments explaining key arguments. Each recommendation is paired with straightforward diagnostic checks (e.g., checking residual plots, variance inflation factors, or convergence checks) that you can execute immediately with Run in Console or Replace.

9 Models, Privacy (ZDR) & Reasoning Levels

In Settings, the model dropdown automatically lists the Top 20 OpenRouter Models. Click Show All Models to load the complete OpenRouter catalog, or type any model ID into the search box.

Reasoning Level Behavior
Model Default (Auto) Uses the selected model's native default behavior.
None Disables reasoning tokens for fastest response times.
Minimal / Low Allocates a light reasoning budget (~10%–20%) for everyday coding and quick checks.
Medium / High Allocates a deeper reasoning budget (~50%–80%) for complex statistical modeling and debugging.

Run converser_inspect_config() in the R Console at any time to verify the active model, reasoning effort, ZDR settings, and loaded skill files.

10 Setting Up SKILL.md or Skill.zip to Guide Coding

What is the Purpose of a Skill File?

Every researcher, lab, or data science workflow has specific preferences—such as using dplyr and native pipes (|>) vs. data.table, fitting models with fixest or lme4, formatting regression tables with modelsummary or gtsummary, or applying a custom ggplot2 theme.

A SKILL.md file (or a Skill.zip bundle) is a persistent instruction playbook that ConverseR automatically appends to the assistant's system prompt. Instead of repeating your coding preferences in every prompt, your active skill ensures the assistant consistently follows your conventions, variable naming rules, and helper functions.

When to Use a Single SKILL.md

Best for defining your preferred R packages, coding style rules, statistical reporting conventions, and short code templates in a single Markdown document.

When to Use a Skill.zip Bundle

Best when your workflow relies on companion files—such as a custom R/theme_lab.R script, helper functions, or a variable dictionary (codebook.csv)—bundled together with SKILL.md.

Step-by-Step: Using Your Existing R Code to Create a SKILL.md

The fastest way to create a tailored SKILL.md is to let ConverseR extract your coding conventions directly from an existing R script and output the entire specification inside a single YAML-formatted code chunk:

  1. Open one of your representative R scripts in RStudio (for example, a script that demonstrates how you clean data, fit models, and format plots).
  2. Highlight the script (or key sections of it) and open the Sidebar with converser().
  3. Copy and send the following prompt in the Sidebar:
Prompt to Generate a Single YAML-Formatted SKILL.md Chunk 
Analyze the coding style, package choices, data wrangling idioms, statistical modeling conventions, and ggplot2 aesthetic patterns in my active R script. Generate a comprehensive SKILL.md specification that I can use as a persistent system skill so future R code you write strictly follows these exact conventions, naming patterns, and helper functions. Output the ENTIRE skill inside a single ```yaml code chunk (using YAML keys and indented `|` block scalars for any code templates, with no nested triple backticks) so I can copy the entire file in one click.
  1. Click Copy on the top-right toolbar of the single YAML (SKILL.md) code block generated by the assistant.
  2. Click Settings in the Sidebar header, scroll to SKILL.md & ZIP Bundle Loader, and paste the YAML content into the editor box (or click Insert Template to start from a built-in YAML template).
  3. Click Save .md to save the file to disk, then click Save & Apply (with Save as default across R sessions checked). A green SKILL badge will appear in the Sidebar header indicating your skill is active.

Creating and Loading a Skill.zip Bundle

If you want the assistant to use your own R helper scripts or reference tables, place SKILL.md and your supporting files (.R, .md, .csv, .yaml) into a folder and compress it into a .zip archive:

Example Skill.zip Folder Structure 
my_lab_skill.zip
├── SKILL.md                  # Primary coding & statistical instructions
├── scripts/
│   └── lab_helpers.R         # Custom ggplot2 theme and regression helper functions
└── references/
    └── codebook.csv          # Dataset variable names and definitions

To activate the bundle, open Settings → SKILL.md & ZIP Bundle Loader, click Upload .md or .zip, select your .zip file, and click Save & Apply. ConverseR extracts the archive into its persistent configuration directory and includes both SKILL.md and your companion resource files in the system prompt.
